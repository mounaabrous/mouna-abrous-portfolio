# Mouna Abrous — Portfolio

A creative, responsive React portfolio built with Vite.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL Vite prints (usually http://localhost:5173).

## Before publishing
- Replace every `YOUR_EMAIL@example.com` in `src/main.jsx` with your professional email.
- Review project descriptions and technology lists to ensure they accurately reflect your individual contributions.
- Add a resume PDF link if you'd like one in the navigation.
- The project thumbnails are original CSS illustrations; replace or supplement them with real screenshots when ready.

## Build and deploy
Run `npm run build` to create the production site in `dist/`. You can deploy the Vite app using Vercel, Netlify, or Firebase Hosting.
